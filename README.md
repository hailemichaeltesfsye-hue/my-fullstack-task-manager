## 📦 Getting Started & Installation

### 1. Clone the repository
```bash
git clone https://github.com/hailemichaeltesfsye-hue/my-fullstack-task-manager
cd my-fullstack-task-manager
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Copy the template `.env.example` to `.env` and configure your database credentials:
```bash
cp .env.example .env
```

### 4. Start the application
```bash
npm start
# or for live reloading:
npm run dev
```

## 🧪 Endpoints & API Reference
- `GET /` — Serves the interactive full-stack user interface.
- `GET /health` — Returns server status, uptime, and system telemetry.
- `GET /api/tasks` — Retrieves all active tasks from the relational database.
- `POST /api/tasks` — Creates a new task record.
